About This Tool

This a is simple 3D cardboard box generator for designers. Adjust real-world dimensions, materials, and viewing angles, then export clean images for mockups and layouts.

  1. Use the control panel to customize the box model, units are in cm
  2. Press "Enter" to execute the changes on text
  3. Click "Export image" to save the model as 1500x1500px image in PNG format
